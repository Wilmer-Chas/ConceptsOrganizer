# Declarative Programming

Focus on **what** needs to be done, not **how** to do it.

## Core ideas

- Describe the desired result or structure
- Let an engine/runtime decide execution details
- Examples: SQL, HTML, many config / query DSLs

## Contrast

Imperative code spells out control flow and state changes. Declarative code states the outcome (e.g. “all users older than 30”) without prescribing retrieval steps.
