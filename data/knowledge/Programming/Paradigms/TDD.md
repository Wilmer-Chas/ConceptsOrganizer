# TDD — Test-Driven Design / Development

Drive design with tests, tightly interleaved with implementation.

## Cycle

1. **Red** — write a failing test  
2. **Green** — write the minimal code to pass  
3. **Refactor** — clean up with tests as a safety net  

## Related

Craft-Conventions (naming / testing habits), unit-test compilation workflow.
