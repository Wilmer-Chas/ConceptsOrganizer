# OOP — Object-Oriented Programming

A paradigm based on **objects** and **classes**.

## Core ideas

- **Encapsulation** — bundle state with the operations that use it; hide internals behind an interface
- **Inheritance** — share and extend behavior through type hierarchies
- **Polymorphism** — treat different concrete types through a common interface

## When it helps

Organizing larger codebases around modeled entities, responsibilities, and reusable abstractions.

## Related

SOLID principles, design patterns (Factory, Strategy, Observer, …).
