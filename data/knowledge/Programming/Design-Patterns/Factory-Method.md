# Factory Method Pattern (Creational)

## Intent

Define an interface for creating objects, but let subclasses (or concrete implementations) decide the concrete type. Decouples instantiation from usage; promotes loose coupling and extension.

## When to use

When clients should depend on abstractions while creation varies by product type or configuration.
