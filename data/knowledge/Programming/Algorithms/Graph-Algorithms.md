# Graph Algorithms

Operate on vertices and edges.

## Traversal

- BFS — O(V + E)  
- DFS — O(V + E)  

## Shortest path

- Dijkstra — O(E log V)  
- Bellman-Ford — O(VE)  
- Floyd–Warshall — O(V³)  

## MST

- Kruskal — O(E log V)  
- Prim — O(E log V)  

Also: topological sort, cycle detection.

## Structures

Adjacency list, adjacency matrix, priority queue, union-find.
