# Sorting & Searching

## Sorting

| Algorithm | Typical cost | Notes |
|---|---|---|
| Bubble | O(n²) | Simple, inefficient |
| Selection | O(n²) | |
| Insertion | O(n²) | Great for nearly sorted |
| Merge | O(n log n) | |
| Quick | O(n log n) avg, O(n²) worst | |
| Heap | O(n log n) | |

## Searching

- **Linear** — O(n)  
- **Binary** — O(log n), needs sorted data  
- **Hash lookup** — average O(1)
