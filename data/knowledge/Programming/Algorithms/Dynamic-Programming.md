# Dynamic Programming (DP)

Solve by breaking into **overlapping subproblems**, cache results, build optimal answers. Useful when the same subproblems repeat and optimal substructure exists.

## Approaches

- **Top-down** — memoization  
- **Bottom-up** — tabulation  

## Classics

Fibonacci · Knapsack (0/1, unbounded) · LCS · Edit Distance · Coin Change · LIS
