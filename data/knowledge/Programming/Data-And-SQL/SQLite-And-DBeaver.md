# Connecting to SQL with DBeaver (SQLite)

Use DBeaver (or similar) as a GUI against a local SQLite file while your C++ (or other) code talks to the same database file.

Typical flow:

1. Create / open a `.sqlite` / `.db` file on disk.
2. Point DBeaver at that file as an SQLite connection.
3. Inspect tables, run ad-hoc SQL, verify what your program wrote.

See also: Cpp-And-SQLite.
