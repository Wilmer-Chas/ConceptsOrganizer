# SOLID Overview

Five OOP design principles for understandable, flexible, maintainable systems.

**Do not follow blindly** — you can obey SOLID and still write bad code. Be aware of them; use judgment.

Reference talk: https://www.youtube.com/watch?v=q1qKv5TBaOA

| Letter | Principle |
|---|---|
| S | Single Responsibility |
| O | Open/Closed |
| L | Liskov Substitution |
| I | Interface Segregation |
| D | Dependency Inversion |
