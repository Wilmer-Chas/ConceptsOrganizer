# How to Package These as “Small Projects”

Each project should answer one unavoidable question:

| Project | Question |
|---|---|
| Shortest path | Why can’t intuition find optimal routes? |
| Sandpile | Why are disasters scale-free? |
| Cooling | Why do exponentials appear everywhere? |
| Power laws | Why are rare events dominant? |
| Metrics | Why does geometry change solutions? |
| Chaos | Why can’t prediction scale? |
| Flow | Why do systems bottleneck? |
| Monte Carlo | How can randomness solve geometry? |
